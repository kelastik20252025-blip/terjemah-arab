# Terjemah Arab — Smart Translator

Website penerjemah dua arah Bahasa Indonesia dan Bahasa Arab, dilengkapi kamus kosakata dasar, materi pengantar Nahwu & Sharaf, serta riwayat lokal.

## Menjalankan
Buka `index.html` melalui browser atau publikasikan repository ini dengan GitHub Pages.

## Fitur
- Terjemahan Indonesia ↔ Arab melalui layanan MyMemory Translation API (membutuhkan internet).
- Tampilan RTL untuk teks Arab.
- Salin hasil dan tukar arah bahasa.
- Riwayat disimpan di browser pengguna.
- Kamus kosakata dan materi belajar dasar.

## Catatan
Layanan terjemahan memakai API pihak ketiga dan memiliki batas/kebijakan layanan sendiri. Hasil terjemahan mesin perlu diperiksa, terutama untuk teks resmi atau keagamaan.
